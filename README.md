# agent-skills

Коллекция переиспользуемых **скиллов (skills)** для [Claude Code](https://claude.com/claude-code) — CLI-помощника от Anthropic.

> **Что такое скилл?** Это папка с файлом `SKILL.md`, где описано, *когда* помощнику включаться и *как* выполнять определённый класс задач. Claude Code сам подхватывает скилл, когда запрос пользователя совпадает с его описанием, либо его можно вызвать вручную командой со слешем — например `/drawio`. По сути это «готовый сценарий работы», который можно один раз написать и переиспользовать в любом проекте.

## Скиллы в коллекции

| Скилл | Что делает |
|---|---|
| [`drawio`](./drawio/) | Создаёт **редактируемые диаграммы** в формате draw.io / diagrams.net (`.drawio`) из текстового описания — блок-схемы, оргструктуры, схемы архитектуры, ER-диаграммы, mind map. Генерирует валидный XML напрямую, аккуратно раскладывает узлы по сетке и открывает файл в приложении draw.io или на app.diagrams.net. |
| [`pm`](./pm/) | **Управление проектами** по PMBOK® 7-е издание (PMI). Полная PM-сессия — диагностика → план → артефакты (устав, WBS, реестр рисков, roadmap) → проверка. |
| [`ba`](./ba/) | **Бизнес-анализ** по BABOK v3 (IIBA) и Карлу Вигерсу. Сбор и проработка требований — SRS/ТЗ, user stories, use cases, BRD/FRD, модели процессов и данных. |
| [`pr`](./pr/) | **Экспертный ассистент по BPMN 2.0** (методология Bruce Silver «Method and Style»). Моделирование бизнес-процессов, проверка диаграмм на корректность, выбор элементов нотации. |
| [`presentation`](./presentation/) | **Презентации в виде одного автономного HTML-файла** хорошего, не «ИИ-шного» дизайна. Собирает слайды 1920×1080 на фиксированных «непротекаемых» CSS-сетках, борется с AI-эстетикой и **сам проверяет вёрстку** скриптом-аудитором (переполнение, наезжание элементов, плейсхолдеры). Открывается в браузере, листается стрелками, печатается в PDF. |
| [`pptx-scramble`](./pptx-scramble/) | **Обратимое обезличивание текста в PowerPoint `.pptx`.** Заменяет каждое слово на «абракадабру» той же длины (буква→буква того же регистра/алфавита, цифра→цифра) — вёрстка, шрифты и цвета не меняются, а реальные слова и числа исчезают. Рядом кладёт карту-«расшифровку» для точного восстановления **по содержимому**: оригинал возвращается, даже если болванку переработали и слова переставили на другие слайды. Чистый Python (стандартная библиотека), компаньон к официальному скиллу `pptx`. |
| [`presentation-suite/`](./presentation-suite/) | **Набор из 4 скиллов для презентаций** из воркспейса Claude Design: `make-deck` (базовая HTML-дека), `p-demo` (конвейер «HTML + зеркальный PPTX» через 5 субагентов), `townhall_decompose-template` (разбор шаблона в дизайн-систему) и `townhall_compose-deck` (сборка деки из дизайн-системы). Общий рантайм слайдов `deck_stage.js` — в комплекте. Подробности — в [README папки](./presentation-suite/README.md). |

## Установка

Скилл — это просто папка. Скопируйте нужную папку из этого репозитория в каталог скиллов Claude Code.

**Глобально (доступно во всех проектах):**

```bash
# Linux / macOS — один скилл
git clone https://github.com/cy94q5pb7v-rgb/agent-skills.git
cp -r agent-skills/drawio ~/.claude/skills/drawio

# …или сразу все скиллы коллекции
for s in drawio pm ba pr presentation; do cp -r "agent-skills/$s" ~/.claude/skills/"$s"; done
```

```powershell
# Windows (PowerShell) — один скилл
git clone https://github.com/cy94q5pb7v-rgb/agent-skills.git
Copy-Item -Recurse agent-skills\drawio "$env:USERPROFILE\.claude\skills\drawio"

# …или сразу все
'drawio','pm','ba','pr','presentation' | ForEach-Object { Copy-Item -Recurse "agent-skills\$_" "$env:USERPROFILE\.claude\skills\$_" }
```

**Только в одном проекте:** скопируйте папку в `.claude/skills/<имя>` внутри корня проекта.

После установки перезапустите сессию Claude Code (или начните новую) — скилл появится в списке. Проверить: вызовите `/drawio` (или `/pm`, `/ba`, `/pr`, `/presentation`) либо просто опишите задачу словами — «нарисуй блок-схему …», «составь план проекта …», «собери требования …», «сделай презентацию …».

## Структура скилла

Минимально скилл — это папка с одним файлом `SKILL.md`. Скилл может дополнительно нести справочники и шаблоны.

`pm`, `ba`, `pr` — одиночный `SKILL.md` (вся методология внутри). `drawio` и `presentation` дополнительно везут справочники, шаблоны и (у `presentation`) скрипт-аудитор:

```
drawio/
├── SKILL.md            # «мозг» скилла: когда включаться + как работать (frontmatter name/description + инструкции)
├── references/
│   └── format.md       # справочник по XML-формату draw.io (стили, узлы, связи, экранирование)
└── templates/
    ├── flowchart.drawio    # готовый каркас блок-схемы
    ├── orgchart.drawio     # готовый каркас оргструктуры
    └── architecture.drawio # готовый каркас архитектурной схемы

presentation/
├── SKILL.md            # «мозг»: режимы → анализ в план-файл → дизайн от содержания → самопроверка
├── templates/
│   └── deck.html       # болванка деки: встроенный движок слайдов + словарь форм + токены
├── references/
│   ├── pipeline.md          # оркестрация для слабой модели: план-файл (память) + субагенты + фолбэк
│   ├── layout-system.md     # словарь форм, бюджет/заполнение, графики, цвет (вкл. пресет Сбер), шрифты
│   ├── anti-ai-checklist.md # признаки «ИИ-деки» и чем заменять
│   └── self-check.md        # уровни проверки + нарратив + сверка с реестром данных
└── scripts/
    └── audit.mjs       # headless-аудит вёрстки: переполнение, наезжание, плейсхолдеры, протёкший текст

pm/  ba/  pr/
└── SKILL.md            # одиночный файл — методичка целиком
```

`SKILL.md` начинается с YAML-frontmatter:

```yaml
---
name: drawio
description: <когда применять скилл + триггерные фразы>
---
```

`description` — самое важное поле: по нему Claude Code решает, относится ли запрос пользователя к этому скиллу. Поэтому в нём перечислены конкретные формулировки-триггеры.
