# Каталог эталонных деков

Список референсов мирового уровня по типам презентаций. Reviewer использует это в Фазе 5 для сверки качества.

Не «общий вайб» — конкретные приёмы, которые сильные деки используют, и конкретные места, где их можно подсмотреть.

---

## Pitch deck (для VC, инвесторов)

**Эталоны:**
- **Airbnb seed deck (2009)** — каноничный шаблон: проблема → решение → market size → product → traction → team → ask. 10 слайдов, ничего лишнего. Каждый слайд — одна мысль.
- **Sequoia pitch template** — структура «10 слайдов, на которые мы смотрим». Чёткая иерархия problem → solution → why now → market → competition → team → financials → ask.
- **Uber pitch deck (2008)** — позиционирование от боли пользователя. Сильный «before/after» приём.
- **Linear seed deck (2019)** — современный pitch с фокусом на product craft. Минималистичная типографика, серьёзная палитра.
- **Y Combinator demo day deck format** — 1 минута / 1 слайд, экстремальная плотность сути.
- **Front (Mathilde Collin) Series A deck** — публично разобран, отличный пример traction-слайдов.

**Что подсмотреть:**
- Hero-слайд с одной фразой, объясняющей продукт за 5 секунд.
- Слайд problem с конкретной болью, не абстракцией.
- Traction-слайд с одной большой цифрой и графиком, не списком из 10 метрик.
- Team-слайд: 3–4 человека, не 12. Релевантный опыт, не CV целиком.
- Ask-слайд: конкретная сумма, конкретное использование, конкретный таймфрейм.

## Product launch (анонс продукта/фичи)

**Эталоны:**
- **Apple keynote slides** — каждый кадр выверен. Большие изображения, минимум текста, ритм через переходы.
- **Stripe Sessions keynotes** — техническая глубина без перегруза. Кейсы клиентов как доказательства.
- **Figma Config talks** — лучшие в индустрии слайды по типографике и информационной плотности.
- **Linear changelog** — анонс фичи через story «before/now», не через bullet list фич.
- **Anthropic / OpenAI launch posts** (как «слайды лонгрида») — структура «proof → context → details → safety → next».

**Что подсмотреть:**
- Одна большая цифра/визуал на «пиковых» слайдах вместо плотного контента.
- Демо-слайды через статичный скриншот + одна стрелка/выноска, а не анимированный gif.
- «Why this matters» секция — не «что мы сделали», а «что это меняет».

## Sales deck (B2B, продающая)

**Эталоны:**
- **Gong sales decks (публичные)** — sequence «их боль → их боль конкретно → почему это дорого → как Gong решает → результаты клиентов → next step».
- **HubSpot sales playbook** — open framework для построения слайдов под конкретного клиента.
- **Salesforce «Customer Success»** — структура case-study слайдов: situation → action → result.
- **Drift sales template** — короткие деки с фокусом на личном relevance для конкретного покупателя.

**Что подсмотреть:**
- Customize-слайд с именем компании-клиента в заголовке.
- Секция возражений и ответов — не прячется, а проговаривается явно.
- ROI-слайд: одна формула, одна большая цифра, источник.

## Internal report (отчёт перед командой/руководством)

**Эталоны:**
- **Amazon 6-pager + appendix slides** — отчёты пишутся как narrative-документы, слайды только для визуализации цифр.
- **Stripe annual letter** — годовой отчёт как нарратив, цифры подчинены story.
- **Buffer transparency reports** — публичные внутренние метрики, минималистичный вижуал.
- **Basecamp Heartbeat** — формат «что сделано / что планируем / что важно знать».

**Что подсмотреть:**
- Не делать «отчёт через bullet points». Делать как нарратив с пиками.
- Цифры подавать через «vs prev period» и «vs target», не голыми числами.
- Финал — «next step» с владельцем и сроком, не «спасибо».

## Educational / explainer (обучение, объяснение концепции)

**Эталоны:**
- **3Blue1Brown video slides** — лучшие в мире по визуализации математики и абстрактных концепций.
- **Bartosz Ciechanowski explainers** (`ciechanow.ski`) — интерактивные лонгриды о физике/механике. Эталон self-paced learning.
- **Stripe Press long reads** — типографически выверенные лонгриды по бизнесу/технологиям.
- **Maggie Appleton talks** — connecting visuals между абстрактными идеями.
- **Andy Matuschak's working notes** — knowledge garden как презентационный формат.

**Что подсмотреть:**
- Один концепт за раз, с проверкой понимания перед движением дальше.
- Визуальные метафоры — конкретные, не абстрактные шейпы.
- Переходы строятся как «теперь, когда мы это знаем, вот что это означает».

## Manifesto / vision (ценностное заявление)

**Эталоны:**
- **Linear method** (`linear.app/method`) — лучший пример manifesto-сайта/деки в SaaS. Бескомпромиссный тон, типографика как герой.
- **Basecamp Shape Up** — методология как deck-нарратив.
- **Stripe Press essays** — глубина и плотность мысли, без лишней визуальности.
- **37signals «It Doesn't Have to Be Crazy at Work»** — manifesto как короткие острые слайды.

**Что подсмотреть:**
- Заголовки — утверждения, не описания. «Мы делаем X», не «О компании X».
- Серьёзная типографика без украшений. Цвет как акцент, не как фон.
- Каждый слайд — заявление, на которое можно согласиться или возразить.

## Conference talk (выступление на конференции)

**Эталоны:**
- **Maggie Appleton talks** — связь концептов через визуальный мостик.
- **Andy Matuschak talks** — глубокая концептуальная плотность.
- **Linear annual report** — формат отчёта как conference-style выступления.
- **Figma Config 2023/2024 talks** — лучший visual game у любых конференционных слайдов.
- **Notion Web 3 talks (Conor White-Sullivan)** — личный тон, скетчи вместо стоковой графики.

**Что подсмотреть:**
- Обложка с большой типографикой — название доклада + имя.
- «Roadmap» слайд в начале — куда мы идём за 30 минут.
- Финальный слайд — тейкэвей одной фразой + Twitter-handle.

## Personal portfolio / personal brand

**Эталоны:**
- **Maggie Appleton site** — лучший в индустрии «about me» через работу.
- **Andy Matuschak site** — public garden как portfolio.
- **Frank Chimero site** — типографический минимализм.
- **Brandon Smith / individual designer portfolios** — фокус на 3–5 кейсах, не 30.

**Что подсмотреть:**
- 3–5 ключевых работ, не «всё что я делал».
- Кейс через story «задача → подход → результат», не скриншот-галерею.
- «Кто я» — две строки, не CV.

## Универсальные приёмы (применимы везде)

- **Большой одиночный визуал на пиковом слайде.** Один объект, один смысл, много воздуха.
- **«Чёрный экран с одной фразой»** — выдох между плотными слайдами. Цитата, тейкэвей, провокация.
- **Сравнение «before / after»** — две колонки, минимум текста.
- **Time-line по горизонтали** — для роста / истории / roadmap.
- **Big number** — одна цифра 200–400px, контекст под ней одной строкой.
- **Quote slide** — цитата клиента/эксперта, без фото-плашки. Имя и роль — мелко под цитатой.
- **Roadmap-слайд по этапам** — не «v1, v2, v3», а «что было — что есть — что будет».
- **Pricing-слайд** — три плана максимум, явный «recommended», цена в крупной типографике.

## Якоря качества — как понять, что дека уровня world-class

1. Каждый слайд можно объяснить одним предложением: «этот слайд существует, чтобы зритель ___».
2. Удалить любой слайд — что-то заметно ломается в нарративе.
3. Hero-слайд держит внимание ≥ 3 секунд без необходимости что-то читать.
4. Финальный слайд запоминается через сутки.
5. Визуальный язык узнаваем — увидев слайд без названия, понятно, что это про этот продукт/тему.
6. На презентации можно говорить голосом — слайды не дублируют речь, а усиливают.
