# Presentations — скиллы для сборки презентаций

Набор из четырёх переиспользуемых скиллов Claude Code для создания презентаций
**без визуального редактора** — прямой генерацией HTML-слайдов с полиграфическим
качеством, борьбой с «ИИ-эстетикой» и самопроверкой вёрстки.

Все скиллы делают деки в формате **одного автономного HTML-файла**: слайды
1920×1080, навигация с клавиатуры (← → пробел Home/End), печать в PDF (один слайд —
одна страница). Движок слайдов — веб-компонент `deck_stage.js` (лежит рядом, см. ниже).

## Скиллы

| Скилл | Что делает | Когда триггерить |
|---|---|---|
| **`make-deck`** | Базовая сборка HTML-деки «с нуля» по брифу. Вкус уровня Claude Design, action-заголовки, строгая сетка, обязательный аудит переполнения. | «сделай презентацию / слайды / pitch deck / keynote» |
| **`p-demo`** | Полный конвейер «презентация под выступление»: обязательное интервью → мастер-промт → цепочка из 5 субагентов (lead-дизайнер → контент-стратег → ревьюер → HTML-разработчик → QA) → зеркальный **PPTX** через python-pptx. | «/p-demo», «продающая презентация», «питч инвестору», «deck + pptx» |
| **`townhall_decompose-template`** | **Разбирает** готовый шаблон (.pptx / HTML-дека / скриншоты) на переиспользуемые элементы дизайн-системы: иконки, фоны, шрифты, логотипы, цвета, раскладки, компоненты + машиночитаемый `manifest.json`. | «разбери шаблон на элементы», «сделай из презентации дизайн-систему / kit» |
| **`townhall_compose-deck`** | **Собирает** презентацию из уже разложенной дизайн-системы (kit + файл с содержанием). Переиспользует реальные элементы по ролям из манифеста, поддерживает конфиденциальные маркеры ХХ/ХХХ. | «собери деку по этой дизайн-системе», «build slides from this kit» |

`townhall_decompose-template` + `townhall_compose-deck` — это две половины одного
**конвейера**: сначала разбираешь шаблон в «корзину запчастей», потом собираешь из
неё сколько угодно новых дек в том же стиле.

## Установка

Скопировать нужную папку скилла в `~/.claude/skills/`:

```bash
cp -r presentations/make-deck ~/.claude/skills/
cp -r presentations/p-demo ~/.claude/skills/
cp -r presentations/townhall_decompose-template ~/.claude/skills/
cp -r presentations/townhall_compose-deck ~/.claude/skills/
```

После этого скилл виден Claude Code и триггерится по фразам из своего `description`
(или явным вызовом `/<имя>`).

## Зависимости

- **`deck_stage.js`** (в этой папке) — рантайм слайдов, который используют `make-deck`
  и `townhall_compose-deck`. Скилл копирует его рядом с итоговым HTML
  (`cp deck_stage.js <папка деки>/`), в самом файле — `<script src="./deck_stage.js">`.
  Можно и вшить содержимое в `<script>…</script>` для полностью автономного файла
  (при инлайне не забудь экранировать `</script>` внутри JS → `<\/script>`).
- **`p-demo`** для зеркального PPTX требует Python + `python-pptx`.
- **`townhall_decompose-template`** для разбора .pptx использует `scripts/pptx_extract.py`
  (Python + Pillow).
- Для превью/аудита вёрстки скиллы рассчитывают на headless-браузер (Chrome через
  Puppeteer/Playwright либо Chrome DevTools MCP).

## Принципы (общие для всех)

Одна мысль — один слайд · заголовок = вывод, а не тема · один шрифт на всю деку,
титул в 5–7× крупнее текста · палитра 60–30–10, максимум 3 цвета · числа — герои
слайда · строгая сетка и большие поля · **никаких** фиолетовых градиентов,
glassmorphism, эмодзи-иконок и текста поверх фото без подложки · обязательная
проверка на переполнение (текст не должен молча обрезаться).

Подробный разбор — в `townhall_compose-deck/references/design-principles.md`
(школа Bonnie&Slide + WCAG + типографические нормы для 1920×1080).
