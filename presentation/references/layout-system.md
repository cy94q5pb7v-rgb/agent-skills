# Система раскладок и бюджет высоты

Это сердце скилла. Слайды строятся **не «на глаз», а из фиксированных сеток, которые физически не могут переполниться**. Модель выбирает роль слайда по имени, копирует готовый блок и подставляет контент — а не сочиняет вёрстку с нуля. Так даже более слабая модель собирает аккуратную деку.

Все классы и токены уже описаны в `templates/deck.html`. Здесь — как ими пользоваться.

---

## 1. Канва и безопасная область

- Слайд = `<section>` внутри `<deck-stage width="1920" height="1080">`.
- У секции `overflow: hidden` — **что вылезло, то молча обрезается**. Поэтому считаем высоту заранее.
- Поля: `132px` сверху и `118px` снизу (место под фирменную рамку), `120px` по бокам → **полезная область 1680 × 830 px**.
- На каждом слайде есть **сквозная фирменная рамка** `.fr` (см. §1.1) — она живёт в полях и контенту не мешает.
- **Заполняй кадр.** Контент должен занимать ~85–95% полезной области, не висеть в центре с пустыми полями. Помогают: полновысотные колонки с линиями (`.layout-cols`/`.stats`), крупные числа, график (`.layout-chart`), бóльшая типографика. Пустота снизу — только как осознанный «воздух» в рамке из линий, не как провал.
- Один `<section>` = один слайд. Дублируй нужную роль, меняй контент.

## 1.1. Фирменная рамка `.fr` (на каждом слайде)

Сквозная «рамка» бренда — то, что отличает «дизайн» от «набора слайдов»:
- сверху слева — логотип-точка + имя бренда (`.wm`), справа — раздел (`.sec`);
- снизу — тонкая линия, слева подпись по смыслу, справа **номер слайда** (`.pg`).

Что менять: «Бренд» → имя бренда; `.sec` → название раздела; левую подпись в `.fr-bot` — по смыслу. **Номер слайда `.pg` движок проставляет сам** — оставь `<span class="pg"></span>` пустым. Рамка помечена `data-decorative` (аудит её игнорирует). Если бренд не нужен — оставь точку с общим именем или убери `.fr`.

## 2. Бюджет высоты (Tier 1 — арифметика «в уме» до генерации)

На типовом слайде «кикер + заголовок + контент» шапка съедает ~240px из 830:

| Элемент | Высота |
|---|---|
| Кикер (`.kicker`) + отступ | ~40px |
| Заголовок (`.title`, ~58px × до 2 строк) | ~140px |
| Зазор до контента (`gap`) | ~50px |
| **Остаётся под контент** | **≈ 590px** |

Жёсткие потолки (держат честность):
- Не больше **3 колонок/карточек** в ряд или **5 строк** графика/списка.
- Большое число (`.num`) — одно на колонку, максимум 3.
- Если заголовок в 1 строку — освобождается ~80px.

**Заполняй этот бюджет, а не оставляй пустым.** Контент-роли (`.layout-cols`, `.layout-stats`, `.layout-chart`) сделаны полновысотными: вертикальные линии-разделители тянутся на всю высоту, контент сверху — нижняя часть остаётся структурированным «воздухом», не провалом. Мало контента → увеличь типографику, добавь реальную цифру / строку графика или объедини слайды (но **не выдумывай** данные ради заполнения).

**Правило «масштаб или разбить» (из Slidev):**
- Контент влезает или чуть-чуть не влезает (≤ ~1.1× бюджета) → ужми: убери строку, уменьши заголовок на шаг, сократи текст.
- Не влезает заметно → **разбей на два слайда**. Не вали всё на один. Переполнение — это смысловая проблема (слишком много на слайде), а не типографская.
- Авто-усадка шрифта (`data-fit`, см. §5) — страховка от длинного слова/числа, **а не** разрешение пихать больше контента.

## 3. Режимы плотности

Один тумблер, задаётся на интервью, влияет на бюджет:

| Режим | Когда | Контента на слайд |
|---|---|---|
| **low** (под доклад) | спикер говорит, слайд — опора | 1 мысль, 1–3 пункта/карточки, крупный шрифт |
| **high** (под чтение/рассылку) | деку читают без спикера | 4–6 пунктов/карточек, плотнее, но в пределах бюджета |

По умолчанию — **low** (выглядит дороже и читается за 3 секунды).

## 4. Роли слайдов — словарь форм, а не меню

> **Готовые copy-paste сниппеты всех форм (целые `<section>` с рамкой), сгруппированные по типу контента — в `references/forms.md`.** Бери оттуда под «что показать» из плана. Ниже — суть и правила форм.


Это **словарь готовых непротекаемых блоков**, из которых ты собираешь нужную форму. **Форму выбирай под содержание слайда** (SKILL.md, принцип «форма следует за содержанием»), а не подгоняй контент под случайную роль. Роли можно **адаптировать и комбинировать**: слить заголовок с числом, поставить график рядом с тезисом, собрать свою сетку на тех же принципах (поля 132/118, бюджет высоты, линии-разделители, `data-fit`, заполнение кадра). Чередуй формы — не повторяй одну раскладку подряд (первый признак «ИИ-деки»).

| Класс | Роль | Что внутри |
|---|---|---|
| `.layout-cover` | обложка / финал | крупный H1 у низа, подзаголовок, подпись |
| `.layout-statement` | один тезис | вертикальная акцентная линия + одна огромная фраза |
| `.layout-cols` | **2–3 аспекта (предпочтительно)** | редакционные колонки: индекс `01/02/03` + линии-разделители |
| `.layout-split` | текст + визуал | слева текст, справа `.ph` (плейсхолдер под картинку) |
| `.layout-cards` | 2–3 аспекта (карточки) | шапка + ряд карточек (`.cards` / `.cards.two`) |
| `.layout-stats` | цифры | шапка + линия + ряд крупных чисел (полновысотные колонки) |
| `.layout-chart` | график по данным | горизонтальные бары: подпись + полоса + значение (показ реальных/посчитанных чисел) |
| `.layout-list` | шаги/пункты | шапка + нумерованный список `01/02/03` |
| `.layout-compare` | сравнение | две колонки-списка (одну можно `.col2.win`) |
| `.layout-quote` | цитата/вывод | большая цитата + автор |

Добавляй `class="... invert"` на 1–2 пиковых слайда (тёмный фон) — это даёт ритм. Не делай все слайды одинаково тёмными.

### Готовые блоки (копируй и наполняй)

> Каждый `<section>` также содержит блок `.fr` (фирменная рамка, см. §1.1) — копируй его из `templates/deck.html`, он одинаковый. Ниже в сниппетах он опущен для краткости.

**Обложка / финал:**
```html
<section class="layout-cover invert">
  <p class="kicker">Кикер</p>
  <h1 data-fit data-fit-min="72">Заголовок-вывод одной фразой</h1>
  <p class="sub">Одно пояснение.</p>
  <p class="by">Автор · Дата</p>
</section>
```

**Тезис:**
```html
<section class="layout-statement">
  <div class="bar"></div>
  <p class="lead" data-fit data-fit-min="52">Одна сильная мысль крупно.</p>
</section>
```

**Колонки (3 аспекта — предпочтительно):**
```html
<section class="layout-cols">
  <div><p class="kicker">Кикер</p><h2 class="title" data-fit data-fit-min="40">Заголовок-вывод</h2></div>
  <div class="cols"><!-- .cols.two для двух -->
    <div class="col"><div class="idx">01</div><div class="ct"><h3>Аспект</h3><p>Коротко, по делу.</p></div></div>
    <div class="col"><div class="idx">02</div><div class="ct"><h3>Аспект</h3><p>Коротко, по делу.</p></div></div>
    <div class="col"><div class="idx">03</div><div class="ct"><h3>Аспект</h3><p>Коротко, по делу.</p></div></div>
  </div>
</section>
```

**График (показ реальных/посчитанных чисел):**
```html
<section class="layout-chart">
  <div><p class="kicker">Структура</p><h2 class="title" data-fit data-fit-min="40">Заголовок-вывод по данным</h2></div>
  <div class="chart"><!-- 3–5 строк; width у .bar-fill = доля от максимума -->
    <div class="bar-row"><div class="blab">Категория</div><div class="bar-track"><div class="bar-fill" style="width:82%"></div></div><div class="bval">82%</div></div>
    <div class="bar-row"><div class="blab">Категория</div><div class="bar-track"><div class="bar-fill" style="width:64%"></div></div><div class="bval">64%</div></div>
    <div class="bar-row"><div class="blab">Категория</div><div class="bar-track"><div class="bar-fill" style="width:41%"></div></div><div class="bval">41%</div></div>
  </div>
</section>
```
> Значения — **только реальные или посчитанные из данных пользователя**. `width` каждого бара = `значение / максимум × 100%`. Не выдумывай числа ради красоты.

**Текст + визуал:**
```html
<section class="layout-split">
  <div>
    <p class="kicker">Кикер</p>
    <h2 class="title" data-fit data-fit-min="40">Заголовок-вывод</h2>
    <p class="body">2–3 строки конкретики: цифры, факты.</p>
  </div>
  <div class="ph">МЕСТО ПОД ВИЗУАЛ<br>(реальный скриншот/схему — спроси у пользователя)</div>
</section>
```

**Карточки (2–3):**
```html
<section class="layout-cards">
  <div><p class="kicker">Кикер</p><h2 class="title" data-fit data-fit-min="40">Заголовок-вывод</h2></div>
  <div class="cards"><!-- .cards.two для двух -->
    <div class="card"><h3>Аспект</h3><p>Коротко, по делу.</p></div>
    <div class="card"><h3>Аспект</h3><p>Коротко, по делу.</p></div>
    <div class="card"><h3>Аспект</h3><p>Коротко, по делу.</p></div>
  </div>
</section>
```

**Цифры:**
```html
<section class="layout-stats">
  <div><p class="kicker">Результат</p><h2 class="title" data-fit data-fit-min="40">Заголовок-вывод</h2></div>
  <div class="stats">
    <div class="stat"><div class="num" data-fit data-fit-min="56">2×</div><div class="lab">подпись</div></div>
    <div class="stat"><div class="num" data-fit data-fit-min="56">−40%</div><div class="lab">подпись</div></div>
    <div class="stat"><div class="num" data-fit data-fit-min="56">12 млн</div><div class="lab">подпись</div></div>
  </div>

```

**Список шагов:**
```html
<section class="layout-list">
  <div><p class="kicker">Кикер</p><h2 class="title" data-fit data-fit-min="40">Заголовок-вывод</h2></div>
  <ul class="list">
    <li><span class="n">01</span><span class="t">Шаг и его результат.</span></li>
    <li><span class="n">02</span><span class="t">Шаг и его результат.</span></li>
    <li><span class="n">03</span><span class="t">Шаг и его результат.</span></li>

```

**Сравнение:**
```html
<section class="layout-compare">
  <div><p class="kicker">Сравнение</p><h2 class="title" data-fit data-fit-min="40">Заголовок-вывод</h2></div>
  <div class="compare">
    <div class="col2"><h3>Было</h3><ul><li>пункт</li><li>пункт</li></ul></div>
    <div class="col2 win"><h3>Стало</h3><ul><li>пункт</li><li>пункт</li></ul></div>
```

**Цитата:**
```html

  <blockquote data-fit data-fit-min="38">«Ключевой вывод или цитата».</blockquote>

</section>
```

## 5. Авто-усадка текста `data-fit` (Tier 2, render-time)

На крупном тексте (`h1`, `.lead`, `.num`, `.title`, `blockquote`) ставь атрибут `data-fit`. Движок при показе слайда **уменьшит шрифт**, если текст вылезает за свою ячейку по ширине/высоте — до `data-fit-min` (минимальный размер в px). Это страхует от длинного слова, большого числа или слишком длинного заголовка. Усадка только вниз, исходный размер берётся из CSS.

`data-fit-min` — пол, ниже которого не уменьшать (иначе текст станет нечитаемым). Если упёрлось в пол и всё равно не влезает — это сигнал «текст длинный, сократи».

## 6. Цвет: по умолчанию — Сбер (белый + зелёный)

**В шаблоне `templates/deck.html` уже зашит фирменный стиль Сбера** (белый фон `#FFFFFF`, зелёный акцент `#21A038`, тёмно-зелёные пиковые слайды, Golos Text, скругления, градиентный знак-логотип). **Ничего перекрашивать не нужно** — просто наполняй контентом.

Правило 60 / 30 / 10: **60–70%** — белый фон (`--bg`); **20–30%** — нейтраль (текст, линии, `--muted`); **~10%** — зелёный акцент (`--accent`) на главное (кикеры, числа, индексы, бары графика). **Не вводи новые цвета по ходу** (никакого красного/синего/фиолетового) — бери только из `:root`.

### Что именно стоит по умолчанию (и как сменить на другой бренд)

Менять `:root` нужно **только если пользователь явно назвал другой бренд**. Текущий дефолт-пресет (Сбер) в шаблоне:

**1. Токены в `:root`** (включают `--accent-l/--muted-d/--line-d` — нужны для тёмных слайдов):
```css
:root{
  --bg:#FFFFFF;
  --bg-invert:#0A2017;      /* глубокий зелёный для 1–2 пиковых слайдов */
  --ink:#0F1B14;
  --ink-invert:#FFFFFF;
  --muted:#5E6B62;
  --muted-d:#9FB5A8;
  --line:#E6EBE7;
  --line-d:#1E3D2B;
  --accent:#21A038;         /* зелёный Сбера */
  --accent-l:#3FCB6E;       /* светлее — на тёмном фоне */
  --card:#F4F8F5;
  --font-display:"Golos Text", system-ui, sans-serif;
  --font-body:"Golos Text", system-ui, sans-serif;
  --font-mono:"IBM Plex Mono", ui-monospace, monospace;
}
```

**2. Шрифт в `<head>`:**
```html
<link href="https://fonts.googleapis.com/css2?family=Golos+Text:wght@400;500;600;700&family=IBM+Plex+Mono:wght@500;600&display=swap" rel="stylesheet">
```

**3. Sber-штрихи** — уже в `<style>` шаблона (скругления + фирменный знак-градиент + зелёный мотив). Под другой бренд адаптируй под его акцент:
```css
.card, .bar-track, .bar-fill, .ph{ border-radius:16px; }      /* скругления — черта Сбера */
.bar-track{ overflow:hidden; }
.wm .dot{ background:conic-gradient(from -40deg,#21A038,#54D06A,#21B8B0,#FFD24D,#21A038); } /* мини-знак Сбера */
.ring{ border-color:rgba(63,203,110,.35); }                    /* мотив — зелёный */
.disc{ background:radial-gradient(circle at 35% 30%, rgba(63,203,110,.22), rgba(33,160,56,.04)); }
```

Правила: зелёный — главный акцент (Сбер по нему и узнают): кикеры, числа, бары графика, индексы колонок, точка-логотип. Фоны зелёным не заливай (1 пиковый тёмно-зелёный слайд + остальные белые). Скругления — последовательно (везде или нигде).

## 7. Шрифты и кириллица (критично)

Если в деке есть русский текст — шрифт **обязан** иметь кириллические глифы, иначе вместо букв «квадраты» (□□□). Проверенные пары с кириллицей на Google Fonts:

| Настроение | Display (заголовки) | Body (текст) |
|---|---|---|
| **дефолт — Сбер** | **Golos Text** | **Golos Text** |
| нейтральный | IBM Plex Serif | IBM Plex Sans |
| современный | — (тот же sans крупно) | Onest / Golos Text |
| технологичный | — | Geologica / IBM Plex Sans |
| редакционный | Lora / PT Serif | IBM Plex Sans |

Избегай дефолтных «ИИ-шрифтов»: Inter, Roboto, Arial, Poppins, Manrope, Montserrat. Подробнее — `anti-ai-checklist.md`.
