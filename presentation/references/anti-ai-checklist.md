# Анти-ИИ чеклист для презентаций

**Обязательный шаг перед сдачей.** Если ловишь хоть один признак — переделай. Это разница между «ещё одной AI-презентацией» и декой, которую не стыдно показать.

ИИ-модели по умолчанию рожают одну и ту же эстетику (учились на Dribbble, Canva-темплейтах и generic SaaS-лендингах). «AI deck» узнаётся с одного экрана. Задача — сознательно так не делать.

> Слабые модели подчиняются **названным запретам** лучше, чем абстрактным пожеланиям. Поэтому ниже — конкретные «нельзя → делай так».

## Цвет

| Признак «ИИ» | Замена |
|---|---|
| Фиолетово-розовый градиент `#7C3AED → #EC4899` на тёмном фоне | Один осознанный акцент. Градиент — только если осмысленный (одна роль, 1–2 слайда). |
| «Cosmic/cyber» палитры — индиго, фуксия, неон | Сдержанная палитра реальных продуктов: Stripe-оранжевый, Linear-серый, Mercury-молочный, Anthropic-кремовый, Vercel-чёрный. |
| Все слайды одинаково тёмные | Чередуй: основной фон + 1–2 инверсных акцентных слайда. Это даёт ритм. |
| 5+ цветов в палитре | 1 фон + 1 акцент + нейтральная шкала. Правило 60/30/10. |
| Радужный градиент-текст | Один цвет. Нужен акцент — увеличь размер или смени гарнитуру, не градиент. |
| Дефолтный синий «корпоративный» | Не уходи в синий по инерции — подбери цвет под тему. |

## Типографика

| Признак «ИИ» | Замена |
|---|---|
| Inter / Poppins / Manrope / Montserrat / Roboto / Arial везде | Осознанный выбор: Geist, IBM Plex, Onest, Golos Text, Geologica, Switzer. Display: Lora, PT Serif, Instrument Serif, IBM Plex Serif. |
| Все заголовки одного веса (700 bold) | Контраст весов: огромный H1 в 300–500 + мелкие caps в 600. |
| Всё центрировано | Левый край — база. Центр — только пиковые слайды с одной фразой. |
| Заголовок + подзаголовок + текст почти одного размера | Сильный контраст: H1 в 4–8 раз больше body. Не плавная градация. |
| Тонкая декоративная линия под заголовком | **Запрещено** — самый явный признак ИИ-слайда. Используй воздух или фон. |

## Иконки и иллюстрации

| Признак «ИИ» | Замена |
|---|---|
| Эмодзи как иконки (🚀 📊 ✨) | Реальный иконсет (Lucide, Phosphor) одним stroke-width. Или вообще без иконок — типографика и цифры справляются. |
| 3D-иконки в стиле «memoji» | Плоские линейные или никаких. |
| Стоковые AI-картинки (gradient blob, абстрактные сферы) | Никакого AI-stock. Нужна картинка — попроси реальную у пользователя. Лучше честный плейсхолдер `.ph`, чем выдумка. |
| Floating-glassmorphism-карточки с blur | Плоские карточки с разделительной линией. Или без карточек — текст и пробел. |
| Карточка «скруглённые углы + цветная полоса слева» | Это AI-троп. Плоская рамка без радиуса, без левого акцента. |

## Layout

| Признак «ИИ» | Замена |
|---|---|
| Симметричный grid 3×3 одинаковых карточек | Асимметрия: одна большая + две маленькие. Или вертикальный список 01/02/03. Или одна мысль = один слайд. |
| Hero: заголовок по центру + кнопка + эмодзи над | Левое выравнивание, заголовок крупнее в 3 раза, визуал не стоковый. |
| «Process» из 4 кружочков со стрелками | Вертикальный нумерованный список с воздухом (`.layout-list`). |
| Одна и та же раскладка на всех слайдах | Чередуй роли: тезис, карточки, цифры, цитата, сравнение. |
| Текстовый слайд без единого визуального якоря | Дай якорь: крупное число, цитату, контраст, плейсхолдер визуала. |

## Копирайт

| Признак «ИИ» | Замена |
|---|---|
| «Unlock your potential» / «Раскройте потенциал» / «Трансформируйте бизнес» | Конкретика: «Сократили code review с 4 часов до 30 минут». |
| «Get Started» / «Узнать больше» как главный CTA | Контекстное действие: «Запросить демо», «Купить за $29», «Прочитать манифест». |
| «In today's fast-paced world…» / «В эпоху ИИ…» | Сразу к делу. Первая строка — конкретный факт. |
| Заголовок-вопрос «Почему мы?» | Не спрашивай про себя. Утверждение или цифра. |
| «Спасибо за внимание» на финале | **Запрещено.** Финал = вывод + действие + контакт. |
| Заголовки-темы: «Понимание X», «Обзор Y», «Про Z» | **Action title** — законченная мысль-вывод: «X сокращает издержки на 30%». См. `self-check.md`. |

## Анимация (если есть)

| Признак «ИИ» | Замена |
|---|---|
| Всё анимируется при появлении (fade + slide up) | Анимация только осмысленная. 80% слайдов появляются мгновенно. |
| Анимации 800–1200ms | 200–500ms максимум. |
| `linear` easing | `cubic-bezier(0.22, 1, 0.36, 1)` или `ease-out`. |
| Бесконечно крутящиеся градиенты на фоне | Статика. Движение — один осмысленный момент. |

## Финальная проверка глазами

1. **Отличу эту деку от 50 других AI-decks с одного взгляда?** Если нет — generic. Найди узнаваемую деталь.
2. **Уберу заголовок — понятно, чей это бренд?** Если нет — дай визуальный язык.
3. **Какой слайд я вспомню через неделю?** Не могу назвать — нет пиковых слайдов, усиль.
4. **Не стыдно показать арт-директору Stripe / Linear / Apple?** Стыдно — переделай конкретные места.
5. **Слайд читается за 3 секунды?** Нет — слишком много текста, режь.

## Когда правило можно нарушить

Всё выше — эвристики, не законы. Есть осознанная причина — нарушай:
- Эмодзи в B2C-деке для подростков — окей.
- Glassmorphism в деке про AR/VR — может работать как метафора.
- Фиолетовый градиент, если это фирменный цвет бренда — окей (тогда это уже не «AI-эстетика»).

Главное: **осознавать**, что нарушаешь паттерн, и иметь причину.
